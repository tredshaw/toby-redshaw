# Portfolio

Personal portfolio site for Toby Redshaw — built from a [Claude Design](https://claude.ai/design) handoff bundle. Static HTML/CSS, React via CDN, no build step.

## Pages

- `index.html` — bento-grid portfolio with sidebar nav, terminal easter egg (`/`), and custom cursor
- `blog.html` — writing index with tag filtering and a featured post
- `article.html` — single-article reading view with scroll progress

## Local

Open `index.html` directly in a browser, or serve the directory:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000/>.
